# Data folder

The raw dataset is **not included** in this repository. The dataset owner asks for attribution and asks that the data is not altered, so please download it from the original source:

1. Open <https://www.kaggle.com/datasets/wisam1985/advanced-iot-agriculture-2024>
2. Download `Advanced_IoT_Dataset.csv`
3. Place it in this folder so the path is `data/Advanced_IoT_Dataset.csv`

Please check the Kaggle page for the dataset's current licence and citation requirements before reusing it.
